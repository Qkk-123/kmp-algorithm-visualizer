看懂代码前，先抓住一句话

课件里那句备注是钥匙：把模式串和它自己对齐，跑一趟匹配。构造 next 数组，本质上就是拿模式串 T 去匹配它自己——指针 i 走在前（相当于"主串"），指针 j 走在后（相当于"模式串"），一边走一边记录"到目前为止最长能对上的前缀有多长"。

于是 next[j] 的定义就是：模式串前 j 个字符里，最长"相等前后缀"的长度。而代码里 next[++i] = ++j 做的，就是把"对上了多长"这个长度顺手存进数组。

三段代码，逐句翻译成人话

  
以 GenNext 为例，看懂这三句，整段代码就通了。

  

    
01
next[0] = -1
这是"哨兵"。当 j 退到 -1，说明模式串第一个字符都对不上，此时要让主串指针 i 前进一步、重新开始。j<0 这个判断就是为它准备的。

    
02
next[++i] = ++j
字符对上了（或 j=-1 强行对齐）。i 和 j 一起前进，同时把"当前匹配长度"j 记录进 next[i]——这就是在填 next 数组。

    
03
j = next[j]
字符对不上。别慌，i 不动，只让 j 沿着 next 往回退，退到"还有可能对上"的位置再比。这正是"利用已匹配信息、不重复比较"。

  


  
示例取自课件《第四章 串》：模式串 T = "ababacac"，主串 S = "ababcabcacbab"。单步结果与课本 next 表 [-1,0,0,1,2,3,0,1] 一致。
