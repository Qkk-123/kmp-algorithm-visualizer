# KMP 算法可视化交互网页

一个用于理解 KMP（Knuth-Morris-Pratt）字符串匹配算法的交互式可视化页面。

## 功能特性

- **next 数组构造**：逐步演示 next（失配）数组的计算过程
- **模式匹配**：演示主串与模式串的匹配过程，展示指针回溯
- **代码逐行高亮**：同步展示当前执行的代码行
- **单步 / 自动播放**：支持上一步、下一步、自动播放
- **键盘操作**：使用 ← → 单步，空格播放/暂停

## 在线演示

https://qkk-123.github.io/kmp-algorithm-visualizer/

## 技术栈

纯 HTML / CSS / JavaScript，单文件实现，无需构建。

## 说明

本项目为学习演示用途，帮助直观理解 KMP 算法的执行逻辑。
